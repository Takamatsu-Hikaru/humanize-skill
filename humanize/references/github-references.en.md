# Tool references and selection

The original skill reviewed these upstream documents on October 12, 2026. Capabilities and URLs may change; check current information when actually choosing a tool. The skill's guidance was written from the user's editing cases, without copying upstream implementations or automatically installing these repositories.

## Writing

[blader/humanizer](https://github.com/blader/humanizer) · [Skill](https://github.com/blader/humanizer/blob/main/SKILL.md)

Relevant ideas include attention to structure and preservation of voice and facts. This skill places more emphasis on narrative, resource organization, and the user's before/after examples. It does not begin with a banned-word list, use detection scores, or routinely show a draft, self-critique, and final version.

## Article images

[baoyu-article-illustrator](https://github.com/JimLiu/baoyu-skills/blob/main/skills/baoyu-article-illustrator/SKILL.md)

Useful ideas include choosing illustration positions from the content and coordinating form, style, and color. Judge image need and density for the actual material rather than requiring one per section. Original figures, screenshots, and precise mechanism diagrams need suitable tools; article illustration does not always mean decorative image generation. Upstream setup and confirmation workflows are not imported as dependencies.

## WeChat conversion

[baoyu-markdown-to-html](https://github.com/JimLiu/baoyu-skills/blob/main/skills/baoyu-markdown-to-html/SKILL.md)

The upstream skill supports inline-styled HTML, optional end references, and treatment of formulas and diagrams. Read the currently installed version if choosing it, and check for unresolved image placeholders. A theme name does not establish visual quality; choose and adjust styles against the user's examples.

[doocs/md](https://github.com/doocs/md) · [Editor](https://md.doocs.org/)

An option for Markdown-based WeChat previews and style adjustments. Its repository documentation was read when this skill was created; importing into the user's WeChat account was not verified. Use the editor when interactive layout helps, but do not migrate a working local process merely to use it. An editor's many available decorations need not all appear in one article.

## Scope

This skill does not depend on these repositories being installed. Handle new dependencies according to the task, environment, and applicable installation rules. Layout, saving a draft, and publishing are separate actions governed by the user's authorization. Creating this skill performs none of those external actions.
